# 퀴즈 실험실 v3.1 — 클래식 화면·결과 개선판

v3에서 정상 작동하던 문제 출제, 답안 1회 제출, 교사 채점, 점수/순위, CSV 기록을 유지하고 **교사/학생의 큰 문제 화면과 정답 공개 → 결과 확인 단계를 추가**한 업데이트입니다.

## 1. 설치 (GitHub Pages)

1. 현재 진행 중인 테스트 게임이 있다면 **게임을 종료한 뒤** 적용하세요. 이미 실행 중인 브라우저에 이전 JavaScript가 남아 있으면 새 코드와 섞일 수 있습니다.
2. `quizlab-v3.1-upgrade.zip` 압축을 풀고 **안의 파일과 js/·tests/ 폴더**를 기존 GitHub 저장소 `slowjjb/classroom-quiz-lab`에 `Add file → Upload files`로 올린 다음 `Commit changes`를 누릅니다.
3. `firebase-config.js`, `database.rules.json`은 이 ZIP에 **포함하지 않았습니다.** 이미 설정한 교사 UID, 문제 세트, 기존 v3 규칙을 덮어쓰지 않습니다.
4. `https://slowjjb.github.io/classroom-quiz-lab/rooms.html`을 열고 `Ctrl+Shift+R`(윈도우 크롬)으로 새로고침합니다. 모바일에서는 **기존 페이지를 닫고 QR을 다시 스캔**해 새 페이지를 여세요.
5. 게임 방 관리 화면·학생 입장 화면 상단에 **v3.1**이 표시되는지 확인합니다.
6. **이번 버전에서는 Firebase 보안 규칙 수정이 필요하지 않습니다.** v3의 `v3/public` 공개 경로 아래에 교사가 직접 채점한 공개 결과만 추가 저장합니다.

## 2. 새 화면의 흐름

### 교사
- `게임 준비 및 입장 마감` → `다음 문제 출제`를 누르면 **교사용 큰 문제 화면이 자동으로 열립니다.**
- 큰 화면 안에서 일시 정지/재개, 10초 연장, 정답 공개, **결과 크게 보기**, 다음 문제 출제를 진행합니다.
- **관리 화면으로** 버튼 또는 `Esc` 키를 누르면 기존 관리자 화면으로 돌아갑니다. 관리 화면의 **문제 크게 보기** 버튼으로 다시 들어갈 수 있습니다.
- 기존 CSV 저장과 문항별 정답률 화면은 유지됩니다.

### 학생
- 문제 출제 시 작은 대기실의 문제 카드가 아닌 **페이지 전체를 덮는 큰 문제 화면**으로 자동 전환합니다. 팝업/새 탭을 열지 않습니다.
- 답을 제출하면 선택이 고정되고 정답 공개를 기다립니다.
- 교사가 정답을 공개하면 같은 큰 화면에 정답/오답, 정답 표시, 이번 문항 점수, 누적 점수가 나옵니다.
- **결과 확인 · 친구들 순위 보기**를 누르면 전체 학생의 이번 문항 정오답·응답 속도·점수와 누적 순위가 나옵니다.
- 교사가 다음 문제를 출제하면 자동으로 새 문제 화면으로 전환합니다.
- 종료 시 최종 순위와 대기실 복귀 버튼을 표시합니다.

## 3. 새 데이터·보안 원칙

- 학생은 여전히 원본 정답이나 다른 학생의 원본 답안을 읽을 수 없습니다.
- `v3/public/<방코드>/roundResults`에 교사가 계산한 **이름/정오답 상태/응답시간/문항 점수/누적 점수**만 정답 공개 이후 저장합니다.
- 한 문제에 답을 제출하지 않은 학생은 `미제출`, 제출 후 채점 대기 중인 경우 `채점 중`으로 표시합니다.
- **정답 공개 전에는 v3/scores 공개 점수를 갱신하지 않도록** 변경하여 정답 유추 가능성을 줄였습니다.
- 이 화면에는 같은 방에 참여한 학생들의 결과가 서로 보입니다. 실제 학생 이름을 쓰기 전 개인정보 및 운영 정책을 검토해야 합니다.

## 4. 권장 검증 순서

1. 새 클래식 테스트 방 + `정상_테스트_20문항` 선택
2. 서로 다른 기기/시크릿 창에 `테스트학생1`, `테스트학생2`로 입장
3. 교사의 `게임 준비 및 입장 마감` → `다음 문제 출제` : **교사·학생 양쪽 큰 화면** 확인
4. 한 학생은 정답, 한 학생은 오답을 제출 → 중복 제출이 차단되는지 확인
5. 교사가 `정답 공개` → 학생의 큰 정답 화면 확인
6. 학생이 `결과 확인` → 두 학생의 정오답·응답 시간·문항 점수·누적 점수 확인
7. 교사는 `결과 크게 보기` → 같은 내용이 큰 화면으로 표시되는지 확인
8. `다음 문제 출제` → 학생 화면이 별도 클릭 없이 다음 문항으로 자동 전환하는지 확인
9. 객관식뿐 아니라 `typing` 주관식도 1개 이상 확인
10. 학생 새로고침 후 답안 중복 방지, 최종 CSV 저장, 종료·방 정리 확인

## 5. 검증 현황과 남은 한계

- 기존 v0~v3의 Node 정적/계산 테스트 통과.
- v3.1 문항 결과 생성·보안 공개 단계·요소 누락/중복 검사 통과.
- 크롬 모의 실행에서 학생의 **문제 풀이 → 제출 → 정답 공개 → 결과 확인 → 다음 문제 → 종료**, 교사의 **큰 문제/결과 화면**, 모바일 화면 너비 검사를 통과.
- 실제 Firebase에 연결한 다기기 회귀 테스트, 30명 동시 답안 제출, 교사 연결 끊김 복구는 **아직 확인하지 않았습니다.** 실제 수업에 쓰기 전에 테스트하세요.
- v3.1도 교사 브라우저가 채점합니다. 교사 창/네트워크가 끊기면 채점·순위 반영이 지연될 수 있습니다.
- 기존 v0·v1 문제 편집 화면의 여백·글자 크기는 이번 업데이트에서 변경하지 않았습니다.

## 6. 버전 복구

문제가 생기면 GitHub의 이전 v3 커밋으로 프런트엔드 파일을 복구할 수 있습니다. Firebase 보안 규칙을 전체 공개하거나 기존 문제 세트/학생 기록을 삭제하지 마세요. 새로운 v3.1 공개 결과 경로는 기존 데이터를 덮어쓰지 않습니다.
