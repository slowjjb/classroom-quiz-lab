# 퍼플킷 v3.14 — 사운드 개선 (v3.13 → v3.14)

기존 Firebase 데이터 구조·보안 규칙·게임 채점은 변경하지 않습니다.

## 변경 내용

- **교사용 사운드 출력 확대**: v3.13 대비 음악·효과음의 **100% 설정 기준 명목 출력 게인 약 5배**. 기존의 중복 감쇠를 제거하고 Web Audio 다이내믹 컴프레서를 적용했습니다. 음량 5배가 사람에게 느껴지는 소리 크기 5배를 보장하지는 않으며, 기기/스피커·중첩 음에 따라 출력이 달라집니다.
- **BGM 3종**: `별빛 산책`, `구름 정원`, `달빛 놀이터`. 외부 음원 파일·저작권 음악 없이 제작한 오리지널 Web Audio 선율입니다.
- **자동 곡 변경**: 기본값 `자동 · 게임마다 변경`이며, 교사가 게임을 새로 **준비**하면 바로 전 자동 재생곡을 피해서 3종 중 한 곡을 고릅니다. 브라우저의 로컬 저장소에는 마지막 자동 곡 ID만 보관합니다.
- **수동 곡 선택**: 교사 화면에서 원하는 곡을 선택할 수 있습니다. 선택하면 이미 음악이 재생 중인 경우 곡이 바뀝니다.
- **별도 볼륨 조절**: 교사 화면에 BGM 0~100%, 효과음 0~100% 슬라이더를 둡니다. 초기값은 BGM 65%, 효과음 75%입니다.
- **편안한 BGM 유지**: BGM을 켠 경우 문제 풀이 중뿐 아니라 정답 공개 전환 때도 계속 흐르고, 게임 종료 시에는 정지해 빵빠레가 잘 들리도록 합니다.
- **학생 기기**: BGM 없음, 기존처럼 효과음만 재생. 효과음은 처음 화면을 누르거나 키보드를 조작한 이후 활성화됩니다.
- **결과 화면의 버튼 복구**: 이전 버전에서 누락됐던 `시상대 접기/펼치기` 버튼의 HTML 요소를 보완했습니다.
- **향후 v4 골드 퀘스트용 긴장감 있는 BGM은 이번에 포함하지 않았습니다.**

## 설치 (GitHub Pages)

1. `purplekit-v3.14-upgrade.zip`을 다운로드하고 압축을 풉니다.
2. https://github.com/slowjjb/classroom-quiz-lab 의 최상위 저장소 화면을 엽니다.
3. `Add file` → `Upload files`를 클릭합니다.
4. 압축을 푼 폴더 **안의 파일과 `js`, `tests` 폴더**를 저장소 최상위로 업로드합니다. 기존 파일과 이름이 같으면 업데이트됩니다.
5. `Commit changes` → GitHub Pages 배포 완료 후 `https://slowjjb.github.io/classroom-quiz-lab/rooms.html`에서 `Ctrl + Shift + R`로 강력 새로고침합니다.
6. 교사 화면에서 `문제 크게 보기` → `BGM 켜기` → BGM 선택 및 두 음량 슬라이더를 테스트하고, 가상 학생 1~2명으로 한 게임을 확인합니다.

**Firebase Realtime Database 규칙, `firebase-config.js`, `database.rules.json`은 이번 버전에서 수정하지 않습니다.**

## 테스트

- 기존 문제 출제·정답 공개·캐릭터 및 결과 기능 관련 Node 검사와 신규 사운드 검사를 포함해 총 **19개 테스트 통과**.
- Chromium 레이아웃 검수에서 1366×768, 1440×900 해상도에서 교사 사운드 설정 패널의 가로 넘침이 없었음.
- 실제 Firebase 실시간 연결, Windows/디벗·교실 스피커의 체감 음량 및 음악 음색은 배포 후 확인 필요.

## 파일 관리

새 CSS 파일을 만들지 않고 기존 `responsive-v3.6.css`와 `js/arcade-ui.js`를 **수정**했습니다. 소스의 버전 표기 및 캐시 쿼리(`?v=3.14`)도 반영했습니다. 저장된 문제 세트와 학생 캐릭터 파일은 그대로 둡니다.
