# Purplekit v5.0.9 — Fishing teacher aquarium and learning results

## 기존 기능 유지
- 클래식·골드 퀘스트 변경 없음.
- 기존 Firebase v5 통합 보안 규칙 그대로 사용. 규칙 재게시 불필요.
- 학생용 낚시·효과음·도감·재접속 복원 유지.

## 변경 사항
1. 낚시 전광판(교사 화면): 학생이 실제로 낚은 생물의 WebP 그림이 바다에 나타났다가 사라집니다. 최근 잡은 생물 기록도 표시됩니다.
2. 자동 게임 종료: 교사 전광판이 최종 kg 순위, 학생별 정답률, 문항별 정답률로 전환됩니다. 첫 시도/전체 시도 선택 지원.
3. 도감 표시: 기존 폭 1320px의 숨김 기준을 1000px로 낮추고, 중간 크기 화면에 맞게 좌우 영역이 줄어듭니다. 1000px 이하에서는 강조된 도감 버튼으로 열어 봅니다. 강제 새로고침은 하지 않습니다.
4. 벌칙: 정답 시 3% → 4.5%, 연출 1.8초 → 2.7초. 기존 교실 전체 60초 쿨다운 유지. 교사 낚시 전광판에도 같은 벌칙 연출이 나타납니다.
5. 캐시 식별자·실행 버전 v5.0.9 / APP_BUILD 509.
