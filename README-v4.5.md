# 퍼플킷 v4.5 — 보물상자 결과 확대 연출

기반: v4.4. 기능: 골드 퀘스트에서 상자 선택 후 Firebase 교사 채점/보상이 확정되면 학생 기기 중앙에 3초 동안 큰 결과 카드 표시. 바로 다음 문제 버튼으로 건너뛰기 가능.

- 골드 증가: 황금색 카드 + 상승 징글
- 골드 감소: 붉은색 카드 + 하강 징글
- 골드 변화 없음: 보라색 카드 + 중립 효과음
- 0G 배수, 빈 상자, 손해 없는 교환 등은 중립
- 보상 타입과 실제 획득/손실액은 Firebase에 이미 기록된 값을 읽습니다. 확률과 채점은 수정하지 않습니다.
- 교사는 게임 진행 중 화면을 열어 두어야 합니다.
- 게임 시간이 끝나면 결과 카드가 닫히고 최종 순위를 표시합니다.
- 새로운 파일 추가 없음. 기존 `gold.css`, `js/gold-core.js`, `js/gold-student.js`, `js/arcade-ui.js`, `js/join.js`, `join.html`을 덮어씁니다.
- Firebase 보안 규칙 변경 없음. 기존 설정 파일, 캐릭터, 문제 데이터 변경 없음.
- GitHub에 ZIP *내부* 파일과 폴더를 업로드하여 Commit, 배포 후 교사/학생 기기에서 강력 새로고침.
- 검증: JS 구문, 자동 테스트, 결과 시나리오. 실제 다중 기기에서는 추후 확인 필요.
