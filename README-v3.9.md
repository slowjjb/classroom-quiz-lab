# 퍼플킷 (PurpleKit) v3.9 — 캐릭터 투명 PNG 교체 1차

## 이번 업데이트
- 승인하신 20명 캐릭터 구성을 그대로 유지하여 배경·카드·이름표를 제거한 개별 투명 PNG 20개
- 완성형 캐릭터 그림: 옷·모자·소품을 별도 파츠로 분리하지 않습니다
- 이미지 전부 480×480 RGBA (실제 캐릭터는 원본 비율 유지, 투명 여백 포함)
- GitHub 파일명 a01.png~a20.png, Firebase에 저장되는 avatarId(a01~a20)는 그대로 유지
- 캐릭터 선택창에 부드러운 이미지 렌더링 적용, 카드 이미지 확대
- 홈/학생 입장/교사 방/문제 관리의 표시 이름을 퍼플킷으로 변경
- 서버 저장 구조/점수/정답 공개/기존 Firebase rules 불변

## 설치
1. `purplekit-v3.9-upgrade.zip` 압축 해제
2. 압축 푼 내부 파일과 `images/avatars` 폴더, `js` 폴더를 그대로 GitHub 저장소 루트에 업로드
3. `Commit changes` 후 학생/교사 화면에서 Ctrl+Shift+R 새로고침
4. 익명 학생으로 접속해 아바타 선택, 명단, 순위/시상대에서 이미지 표시 확인
5. Firebase 보안 규칙 변경 불필요 (v3.8 때 이미 적용됐다면 그대로 유지)

## 완성형 배경 추가는 이후
- 캐릭터 PNG는 진짜 투명 알파를 포함합니다.
- 앞으로 별도 배경 이미지를 제작해 뒤에 레이어로 겹치면 됩니다.
- 이미지 자산만 교체하므로 학생의 기존 캐릭터 선택과 점수 데이터는 유지됩니다.

## 원본 해상도 주의
- 승인하신 5×4 UI 그림 한 장에서 20명을 분리했습니다.
- 480×480/640×640은 여백 포함 캔버스 크기이며 원본이 가진 그림 디테일이 새로 늘어난 것은 아닙니다.
- 현재 앱의 캐릭터 선택/순위 화면에는 적합하지만 대형 인쇄용이라면 별도 고해상도 원화가 필요합니다.

## 앞으로의 확장
- 완성형 배경 ID + 캐릭터 ID 조합만 저장하는 방식 권장
- 학생별 배경 구매를 연동할 때 학급은행 구글시트는 별도 인증 및 서버 검증 필요
