문제 세트 관리

블루킷 CSV를 불러와 검증·수정하고 교사용 비공개 데이터베이스에 저장합니다. 아직 학생에게 문제를 배포하지 않습니다.

교사 인증 및 데이터 보안

확인 중

로그인 상태를 확인하고 있습니다.

v3 통합 규칙 등록이 필요합니다.

현재 로그인한 교사 UID로 기존 v0~v3 기능을 모두 보존하는 통합 규칙을 생성합니다. 두 곳(GitHub 파일과 Firebase 규칙)에 같은 내용을 적용해야 합니다.

저장된 문제 세트

0개

교사용 Firebase 영역에 저장됩니다. 같은 교사 계정으로 접속하면 다른 기기에서도 관리할 수 있습니다.

문제 세트를 불러오는 중입니다.

CSV 가져오기 및 문항 편집

초안 없음

A 번호 · B 문제 · C~F 보기/주관식 허용 답 · G 시간 · H 객관식 정답 번호 · I 공란 · J typing · 이미지 주소는 별도 입력

테스트 CSV를 업로드하여 시작해 보세요.

이미지는 GitHub의 images/questions 폴더에 먼저 업로드한 뒤, 각 문항의 이미지 파일명을 입력하세요. PNG/JPG/WebP를 지원합니다. CSV 10열 형식은 변경하지 않으며 이미지 연결은 Firebase 세트에만 보존됩니다.

중요: 정답은 GitHub 공개 파일이나 학생 화면이 아닌 교사용 Firebase 경로에 저장됩니다. 실제 학생 개인정보는 아직 입력하지 마세요.
