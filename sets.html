문제 세트 관리

블루킷 10열·퍼플킷 11열 CSV를 모두 불러옵니다. K열에 파일명이 있으면 문제 이미지를 자동으로 연결하고, GitHub에 실제 파일이 있는지도 검사합니다.

교사 인증 및 데이터 보안

확인 중

로그인 상태를 확인하고 있습니다.

v3 통합 규칙 등록이 필요합니다.

현재 로그인한 교사 UID로 기존 v0~v3 기능을 모두 보존하는 통합 규칙을 생성합니다. 두 곳(GitHub 파일과 Firebase 규칙)에 같은 내용을 적용해야 합니다.

저장된 문제 세트

0개

교사용 Firebase 영역에 저장됩니다. 같은 교사 계정으로 접속하면 다른 기기에서도 관리할 수 있습니다.

문제 세트를 불러오는 중입니다.

CSV 가져오기 및 문항 편집

기존 10열 CSV도 그대로 사용 가능하며, 이미지가 있는 세트만 K열을 사용합니다.

초안 없음

A 번호 · B 문제 · C~F 보기/주관식 허용 답 · G 시간 · H 객관식 정답 번호 · I 공란 · J typing(주관식만) · 선택 K: 이미지 파일명. 이미지가 없으면 10열만 사용합니다.

퍼플킷용은 이미지가 하나도 없으면 10열로 저장합니다. 블루킷용으로 내보내면 이미지 파일명은 제외됩니다.

CSV를 업로드하여 시작해 보세요.

이미지 파일은 GitHub의 images/questions 폴더에 먼저 여러 개 업로드하세요. 퍼플킷 CSV의 K열에 파일명만 기입하면 자동 연결합니다. 한글 이름·PNG/JPG/WebP를 지원합니다. 파일 확인은 GitHub Pages 배포가 끝난 뒤 실행하세요. 파일 없음/네트워크 확인 불가 경고는 구별하며, 파일 누락 경고만으로 저장을 막지 않습니다.

중요: 정답은 GitHub 공개 파일이나 학생 화면이 아닌 교사용 Firebase 경로에 저장됩니다. 실제 학생 개인정보는 아직 입력하지 마세요.
