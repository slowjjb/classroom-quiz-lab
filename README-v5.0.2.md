# 퍼플킷 v5.0.2 — 생물 8종 및 루어 2종 개별 스프라이트

v5.0.1 전체 프로젝트를 기반으로 이미지 자산만 개선한 버전입니다. 기존 게임/Firebase 로직은 변경하지 않았습니다.

- 독립적인 1024×640 투명 PNG: 일반 생물 8종
- 루어 Lv.1, Lv.2: 신규 픽셀아트 개별 PNG
- 3단계 이상 루어: Lv.2 이미지를 임시 재사용하며 UI에는 실제 레벨 숫자 표시. 다음 제작 차수에서 교체 예정
- 이전에 수정한 강화 진행도 비노출 설정 그대로 유지
- **주의**: 일반 생물 8종 외 15종은 기존 임시 이미지를 유지합니다. 완전 교체는 다음 차수에서 진행합니다.

## 시험

1. `fishing-demo.html`을 로컬 브라우저에서 열기 (미리보기)
2. 고등어·광어·복어·날치·해파리·연어·장어·꽃게 확인
3. 루어 강화 1→2단계 시 다른 새 루어 그림 확인
4. 전체 프로젝트 배포 전 기존 v4.12 안정판 백업
