# 퀴즈 실험실 v3.4 — 가로 화면 최적화 및 교사용 BGM 조절

배포 목적: v3.3 안정성을 유지하면서 학생용 디벗 가로 화면의 가독성/스크롤을 개선하고, 교사와 학생의 오디오 역할을 분리합니다.

## 기능

- 학생 입장 화면: 넓은 화면(너비 900px 이상)에서 왼쪽 참여 코드·이름 / 오른쪽 방 이름·접속 명단. 좁은 화면에서는 세로로 표시.
- 학생 문제 화면: 넓은 화면(너비 760px 이상, 높이 540px 이상)에 왼쪽 상태·진도·남은 시간·타이머 게이지, 오른쪽 문제·그림·2×2 보기·제출 버튼. 긴 문장, 큰 그림, 매우 작은 해상도에서는 정상적인 세로 스크롤 허용.
- 교사 집중 화면: 왼쪽 시간·BGM·출제 관리 버튼, 오른쪽 문제·보기. 정답 공개·결과 화면도 공간 활용 개선.
- 학생 사운드: BGM과 사용자 소리 버튼 제거. 실제 사용자 조작 이후 정오답·선택·제출 효과음만 활성화. 브라우저 정책/기기별 볼륨 설정의 영향을 받음.
- 교사 사운드: BGM 사용 버튼과 0~100% 음량 슬라이더. 기본 60%는 v3.3 BGM 버스 gain 0.18의 세 배인 0.54를 사용. 교사 음량은 해당 기기에서만 적용하며 Firebase에 기록하거나 학생 기기를 원격 제어하지 않음.
- 기존 v3.2 채점·점수·정답 자동 공개·문제 이미지·CSV·Firebase 데이터 구조는 변경하지 않음.

## 설치 (v3.3 설치 및 Firebase 규칙 적용 완료 기준)

1. 현재 저장소를 백업하거나 GitHub 커밋을 기록합니다.
2. `quizlab-v3.4-upgrade.zip`을 다운로드해 압축 해제합니다.
3. 압축 해제된 파일/폴더를 GitHub 저장소 루트 `classroom-quiz-lab/`에 올려 **같은 경로의 기존 파일을 덮어씁니다**.
4. GitHub Pages 배포 완료 후 교사 `rooms.html`과 학생 `join.html`에서 **Ctrl+Shift+R**로 새로고침합니다. 모바일은 사이트 데이터 캐시를 새로고침합니다.
5. 교사/학생 각 1명으로 3~5문항을 출제하면서 이미지와 정오답·시간 표시를 확인합니다.

**Firebase 설정·Realtime Database 규칙 수정은 없습니다.** `firebase-config.js` 및 `database.rules.json`을 업그레이드 ZIP에 포함하지 않았습니다.

실제 Firebase 20명 동시 제출, 학교 디벗 전체 기종, 실제 스피커 음량/오디오 권한은 사용자 측 검증이 필요합니다.

## 파일 구성

- `responsive-v3.4.css` — 신설 반응형 레이아웃
- `join.html`, `rooms.html`, `index.html`, `sets.html` — 뷰포트·버전·리소스 연결
- `js/arcade-ui.js` — 학생 효과음 전용, 교사용 BGM 슬라이더
- `js/join.js`, `js/classic-student.js`, `js/classic-host.js` — v3.4 캐시 우회용 import 경로
- `tests/` — 회귀 검사 및 v3.4 신규 검사

## 알려진 고려 사항

- 긴 문장·많은 텍스트를 포함하는 그림·더 작은 해상도에서는 한 화면 완전 표시를 보장하지 않으며, 내용을 자르는 대신 스크롤을 허용합니다.
- 학생 효과음은 입장이나 터치/키 입력 등 최초 사용자 동작 후에만 재생될 수 있습니다. 학생 기기의 자체 볼륨과 브라우저 사운드 권한은 교사 웹앱에서 일괄 조정하지 않습니다.
- 교사 화면은 채점 엔진을 담당하므로 게임 중 열린 상태를 유지해야 합니다.
