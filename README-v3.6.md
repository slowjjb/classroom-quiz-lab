# 퀴즈 실험실 v3.6 | 학생 정답 확인 화면 개선

## v3.5에서 달라진 점

- 학생 정답 공개 화면의 큰 문제 카드 안에 `정답`을 중앙에 강조하여 표시합니다.
- 같은 화면에서 `내 선택`, `이번 문제 점수`, `누적 점수`, `친구들 순위 보기`를 확인할 수 있습니다.
- 이미지가 있는 문제의 정답 공개 화면에서는 이미지와 정답을 가로 배치하여 아래 정보가 화면 밖으로 밀리는 현상을 줄였습니다.
- 선택한 보기는 더 진한 색·굵은 테두리·`선택` 배지로 구분합니다.
- `정답 제출하기` 버튼을 확대했습니다.
- 메인 페이지·교사 방 관리·문제 세트 관리의 버전 표기를 v3.6으로 통일했습니다.

## GitHub Pages 업로드 방법

1. `quizlab-v3.6-upgrade.zip`을 압축 해제합니다.
2. GitHub의 `slowjjb/classroom-quiz-lab` 저장소 **최상위**에서 `Add file` > `Upload files`로 들어갑니다.
3. 압축 해제한 폴더 **안의 파일들** (`index.html`, `join.html`, `rooms.html`, `sets.html`, CSS, `js` 폴더 등)을 그대로 업로드합니다.
4. 기존 파일 덮어쓰기를 확인하고 `Commit changes`를 누릅니다.
5. 교사·학생 양쪽에서 Ctrl+Shift+R로 강력 새로고침합니다.

## 중요한 주의사항

- **Firebase 보안 규칙 / firebase-config.js / 기존 게임 데이터는 변경하지 않습니다.**
- 기존 v3.5의 문제·채점·점수·자동 공개 로직은 유지합니다.
- 교사 화면의 외형은 v3.5와 같으며 버전 표기만 v3.6으로 표시됩니다.
- 실제 학생·Firebase에서의 동시 제출 검증은 별도로 필요합니다.
- 테스트 화면 검증은 브라우저 모의 데이터로 수행했습니다. 긴 글·큰 이미지·브라우저 확대 배율에 따라 일부 화면은 스크롤될 수 있습니다.
