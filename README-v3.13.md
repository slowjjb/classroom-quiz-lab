# 퍼플킷 v3.13 — 교사용 정답 확대·빵빠레·3열 학습 분석

v3.12 → v3.13 업그레이드입니다. Firebase 데이터 구조와 보안 규칙, 학생 문제 풀이 채점 로직은 바꾸지 않습니다.

## 신규 기능

1. **교사용 정답 크게 표시**
   - 정답 공개 시 문제 카드 중앙에 `정답`, 정답 내용, 학급 정답자 수와 정답률을 표시합니다.
   - 이미지 문제가 있는 경우 왼쪽 이미지 + 오른쪽 정답 카드로 표시합니다.
   - 보기 4개와 학생 화면은 기존처럼 유지됩니다.

2. **게임 종료 빵빠레**
   - 브라우저 Web Audio API를 사용하는 오리지널 효과음입니다.
   - 교사가 `다음 문제 출제`를 누르면 브라우저 오디오가 활성화되며, 게임 종료 시 빵빠레가 자동 재생됩니다.
   - 마지막 결과 화면의 `🎺 빵빠레 다시 재생` 버튼으로 다시 들려줄 수 있습니다.
   - BGM을 꺼도 효과음은 사용할 수 있습니다.
   - 브라우저/기기 정책에 따라 사용자의 클릭 없이 자동으로 음향을 시작할 수 없는 상황은 재생 버튼을 사용합니다.
   - 학교 스피커의 실제 크기는 연결 기기에서 조정하세요.

3. **3열 학습 분석 대시보드**
   - 왼쪽: 누적 점수 순위와 캐릭터.
   - 가운데: 학생별 정답률과 색상 막대.
   - 오른쪽: 문항별 정답률과 색상 막대.
   - 색 구분: 75% 이상 초록, 50% 초과~75% 미만 노랑, 50% 이하 빨강.
   - 학생별 정답률 = 지금까지 공개된 문항 중 맞힌 문항 수 ÷ 공개된 문항 수.
   - 문항별 정답률 = 해당 문항 정답자 수 ÷ 게임 준비 시 확정한 참가자 수.
   - 미제출은 정답에 포함되지 않습니다. 학생별·문항별 비율을 **서로 다른 분모**로 계산하므로 설명에 유의하세요.
   - 시상대를 본 뒤 `시상대 접기`로 3열 분석을 크게 볼 수 있습니다.
   - 전체 화면을 교실에 보여줄 때는 `학생별 정답률 이름 가리기`를 이용할 수 있습니다.

## GitHub 업로드

1. `purplekit-v3.13-upgrade.zip`을 다운로드한 뒤 압축을 풉니다.
2. GitHub 저장소 https://github.com/slowjjb/classroom-quiz-lab 접속.
3. `Add file → Upload files`에서 **압축 해제한 폴더 안의 내용**을 업로드합니다.
4. 루트의 HTML, CSS 파일과 `js`·`tests` 폴더가 기존 위치에 들어가는지 확인합니다.
5. `Commit changes`를 누른 뒤 GitHub Pages 배포가 끝나면 교사 `rooms.html`에서 `Ctrl + Shift + R`을 누릅니다.
6. 가상 학생 2명으로 게임 시작 → 정답 공개 → 게임 종료 → 분석표/빵빠레를 확인하세요.

**Firebase Realtime Database 보안 규칙, firebase-config.js, database.rules.json을 수정하지 마세요.**

## 배포 파일

- `rooms.html`: 교사 게임 화면·분석 마크업
- `arcade.css`, `responsive-v3.6.css`: 화면 스타일
- `js/classic-host.js`: 교사 전용 공개/분석 렌더링
- `js/classic-analytics.js`: 새 분석 계산 모듈
- `js/arcade-ui.js`: 오리지널 빵빠레·효과음 동작
- 다른 주요 HTML: 버전 표시를 v3.13으로 일치
- `tests/`: 변경된 버전 표기 테스트와 신규 분석/사운드 테스트

## 검증 범위

기존 단위·정적 검사와 신규 정답률/오디오 검사 18개 통과. 브라우저 1366×768, 1440×900에서 정답 확대·3열 대시보드 가로 넘침 확인. 실제 Firebase 및 19명 동시 수업, 실제 스피커 음향은 배포 후 재검증이 필요합니다.
