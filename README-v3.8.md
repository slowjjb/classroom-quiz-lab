# 퀴즈 실험실 v3.8 — 캐릭터 20종, 대기실 선택, 실시간 순위·시상대

## 새 기능

- 자체 제작 128×128 PNG 픽셀 캐릭터 20종(사람·동물·상상 생물·로봇)
- 대기실의 **캐릭터 고르기** 버튼 → 팝업에서 캐릭터 선택
- 학생이 고른 캐릭터를 자신의 현재 게임 방 Firebase 프로필 `avatarId`에 저장
- 교사·학생 대기실의 참가자 명단에 실시간 캐릭터 표시
- 클래식 문제별 친구 순위, 누적 순위, 교사 순위표, 최종 1~3위 시상대에 캐릭터 표시
- 캐릭터 중복 선택 가능, 전부 무료
- 기존 학급은행과 연결하지 않음(연동은 추후 별도 개발)

## 업그레이드 (중요: GitHub + Firebase 규칙 두 곳)

1. 현재 v3.7을 GitHub 커밋으로 보관한 상태에서 `quizlab-v3.8-upgrade.zip` 압축을 풉니다.
2. 압축 해제한 **최상위 파일들과 `js/`, `images/avatars/`, `tests/` 폴더**를 GitHub 저장소 루트에 업로드하고 Commit 합니다.
   - `firebase-config.js`와 기존 문제 세트는 건드리지 않습니다.
   - 새로운 CSS는 **`avatars.css` 한 개**뿐이며, `responsive-v3.6.css`는 그대로 사용합니다.
3. 교사 계정으로 `rooms.html`에 로그인합니다.
4. **`v3.8 캐릭터 저장 보안 규칙 설정`** 항목을 펼치고 **`v3.8 전체 보안 규칙 복사`**를 누릅니다.
5. Firebase 콘솔 → `classroom-quiz-lab` → Realtime Database → **규칙(Rules)** 에 복사한 JSON 전체를 붙여넣고 **게시(Publish)** 합니다.
   - 이 JSON은 기존 v0/v1/v2.1/v3 보안 규칙을 통합한 버전입니다. 새 기능은 본인 프로필의 `avatarId`만 추가로 허용합니다.
   - 기존에 보안 규칙을 수동 편집했다면 게시 전에 차이를 먼저 확인하세요.
   - 저장소의 `database.rules.json`도 동일한 내용으로 동기화해 두면 좋습니다(있는 경우).
6. 두 기기로 학생 입장 링크 `join.html`에 접속합니다. 각각 서로 다른 이름으로 참여한 뒤 캐릭터를 선택하세요.
7. 한 기기에서 캐릭터를 바꿀 때 상대 기기의 친구 명단과 교사 명단에 즉시 반영되는지, 새로고침 후에도 유지되는지 확인합니다.
8. 클래식 게임을 진행해 문항 결과·친구 순위·최종 시상대의 캐릭터를 검증합니다.

## 파일 구조

- `images/avatars/a01.png` ... `a20.png` (각 128×128, 투명 배경)
- `js/avatars.js` (캐릭터 목록, 파일 경로, 캐릭터 이미지 생성 유틸)
- `avatars.css` (캐릭터 선택창과 순위 스타일)
- `js/join.js` (프로필 저장 및 대기실 표시)
- `js/rules-v3.js` (기존 통합 규칙에 avatarId 검증 추가)
- `js/classic-core.js`, `js/classic-host.js`, `js/classic-student.js`, `js/arcade-ui.js` (결과·순위·시상대 표시)

## 데이터 보호

- 캐릭터 이미지에는 저작권이 있는 게임 캐릭터나 이모지가 포함되지 않습니다.
- 학생에게 점수 쓰기 권한을 추가하지 않습니다. 학생은 **본인 방 프로필**의 `avatarId`만 수정 가능합니다.
- 기존 프로필(avatarId가 없는 경우)도 사용 가능하며, 기본 캐릭터 a01이 표시됩니다.
- 퀴즈별 랭킹 점수 계산, 문항 정답 판정, CSV 업로드 형식은 기존 버전과 동일합니다.
- 새로운 캐릭터는 Firebase Storage가 아닌 공개 GitHub Pages의 정적 이미지로 제공됩니다.
