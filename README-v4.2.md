# 퍼플킷 v4.2 — 골드 퀘스트 보상 확장 및 정답률 분석

## 이번 업데이트

- **확정된 보상 17종 / 총확률 100%** 적용. 보물상자 3개 모두 동일한 확률표를 사용합니다.
- 보유 골드 2배·3배는 단순 곱셈입니다. **0G에서 2배·3배를 받아도 0G**이며, 최저 지급 예외는 없습니다.
- 매우 희귀한 보상인 전부 빼앗기·전부 교환·전부 잃기는 각각 **0.1%**로 적용했습니다.
- 공격형 보상 비활성화 또는 참여자 1명일 때는 빼앗기·교환을 제외하고 나머지 확률을 비례 조정합니다.
- 교사 화면에서 게임 종료 후 **누적 골드 순위 / 학생별 정답률 / 문항별 정답률**을 3단으로 표시합니다.
- 정답률 **첫 시도 / 전체 시도** 전환, **시상대 접기**, **이름만 가리기** 기능을 제공합니다.
- 학생이 같은 문항을 반복할 수 있으므로 기본값은 **학생별 각 문항 첫 시도 정답률**입니다. 전체 시도를 선택하면 반복 응답을 모두 포함합니다. 한 번도 풀지 않은 문항은 0%가 아니라 `—`로 표시합니다.
- 색상 기준: **75% 이상 초록**, **50% 초과 ~ 75% 미만 노랑**, **50% 이하 빨강**, **응답 없음 회색**.
- 교사의 채점 횟수 갱신과 보물 보상 계산을 Firebase Realtime Database 트랜잭션으로 변경했습니다. 서로 겹치는 갱신에서 예전 골드 잔액으로 덮어쓰는 위험을 줄이고, 동일한 보물 선택의 이중 지급을 막습니다.

## 설치 방법 (v4.1 → v4.2)

1. `purplekit-v4.2-upgrade.zip` 압축을 풉니다.
2. `https://github.com/slowjjb/classroom-quiz-lab`에 접속하여 **Add file → Upload files**.
3. 압축을 푼 **폴더 안의 모든 파일 및 `js`, `tests` 폴더**를 저장소 최상위에 업로드합니다. ZIP 자체는 올리지 마세요.
4. `Commit changes`를 누릅니다.
5. GitHub Pages 배포 후 `https://slowjjb.github.io/classroom-quiz-lab/rooms.html`을 열고 **Ctrl+Shift+R**.
6. 골드 퀘스트 새 방을 준비한 뒤 가상 학생 2~3명으로 게임을 끝까지 확인합니다.

이번 업데이트는 **Firebase 규칙 및 데이터 경로를 변경하지 않습니다**. 기존 `database.rules.json`, `firebase-config.js`, 캐릭터 PNG 및 문제 세트를 삭제·수정하지 마세요.

## 테스트 현황 및 제한

- Node.js 자동 검사 **21개 테스트 파일 통과**.
- 17종 확률을 1,000개 표본 위치에 대해 전수 검증, 첫/전체 시도 정답률·미응답 처리 검증.
- 실제 교사 전광판 JavaScript를 가상 데이터로 실행해 시상대/정답률 전환/이름 가리기까지 검사.
- 브라우저 가로폭 1366px 및 1440px에서 3열 레이아웃 검수.
- **실제 Firebase와 학생 20명의 동시 보상 처리 및 학교 네트워크는 아직 재검증하지 않았습니다.** 교사 브라우저를 열어 두고, **같은 방을 두 개 교사 탭에서 동시에 운영하지 마세요.**
- 기존 v4.1 진행 중인 방은 확률이 중간에 달라질 수 있으므로, 보상 확률 비교를 위한 테스트는 **새 방에서 시작**하는 것이 좋습니다.
