# 퍼플킷 v4.6 — 골드 퀘스트 반복 문항 보기 자동 섞기

## 변경 내용
- **골드 퀘스트 객관식에만 적용**: 교사가 각 문항을 학생에게 발급할 때 보기 4개의 위치를 무작위로 바꿉니다.
- 학생마다 독립적으로 섞습니다. 같은 학생에게 동일한 문제가 다시 나오면 **직전에 표시된 순서와 정답 버튼 번호 둘 다 달라지게** 만듭니다(선택지 2개 이상일 때).
- 보기가 바뀐 상태에서도 정답 판정은 원래 CSV의 정답(H열)과 비교해 올바르게 처리됩니다. 학생에게는 정답 번호 정보가 전송되지 않습니다.
- 원래 보기 순서의 대응 관계를 Firebase의 학생별 `v4/memberState`에 저장합니다. 학생이 다시 접속하거나 순위표가 갱신돼도 현재 문제의 순서가 바뀌지 않습니다.
- 틀렸을 때의 정답 안내에는 **그 학생에게 표시된 정답 번호**를 사용합니다.
- 교사용 골드 퀘스트 결과 CSV의 `제출 답` 열은 `2번: 보기 내용`처럼 표시합니다(신규 채점 기록부터). 첫 시도·전체 시도 정답률 분석은 동일하게 유지됩니다.
- **주관식, 클래식 모드, 보물상자 종류/확률, 이미지, 사운드 등은 변경하지 않습니다.**

## 설치 (v4.5 → v4.6)
1. `purplekit-v4.6-upgrade.zip`을 다운로드하고 압축을 풉니다.
2. GitHub `slowjjb/classroom-quiz-lab` 저장소 최상위에서 `Add file → Upload files`로 **압축 해제한 파일과 폴더의 내용**을 업로드합니다. ZIP 파일을 그대로 업로드하면 안 됩니다.
3. 기존 파일을 덮어쓰고 Commit 합니다. `js` 폴더를 포함하여 업로드합니다.
4. Pages 배포 완료 후 **교사 rooms.html과 학생 join.html 모두 강력 새로고침(Ctrl+Shift+R)** 하세요. 화면 버전 v4.6을 확인합니다.
5. **새 골드 퀘스트 방**을 만들어 반복 문항의 보기 변경과 채점을 시험하는 것이 좋습니다. 기존 방을 재사용하면 v4.5에서 이미 출제된 문항은 기존 순서로 유지되며 이후 발급부터 새 기능이 적용됩니다.

## Firebase 및 데이터
- **Realtime Database 보안 규칙 변경 없음**: 이미 v4.1 이후 통합 규칙을 게시했다면 그대로 사용합니다.
- 기존 `firebase-config.js`와 `database.rules.json`을 수정하거나 업로드하지 마세요. 업그레이드 ZIP에 포함되지 않습니다.
- 기존 문제 세트 CSV, 학급 데이터, 이미지, 게임 결과는 삭제하지 않습니다.
- 원래 정답 정보는 교사 전용 `v4/privateRuns`에 유지됩니다.

## QA 결과
- JavaScript 문법 검사 및 Node 자동 테스트 25개 통과(새 `test-v4-6-shuffle.mjs` 포함).
- 4개 정답 위치마다 바뀐 보기에서 정답과 오답을 올바르게 구분하는지 테스트했습니다.
- 동일 문제가 재등장할 때 이전 보기 순서와 정답 버튼 번호가 달라지는지 180회 반복 테스트(고정 RNG 포함), 250회 의사난수 테스트로 검증했습니다.
- 주관식 및 v4.5 이전 발급 문항의 정답 판정 호환성 확인.
- **실제 학생 기기/Firebase 다중 접속 검사는 배포 후 실시해야 합니다.** 교사 브라우저는 계속 열어 두세요.
