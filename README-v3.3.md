# 퀴즈 실험실 v3.3 — 아케이드 디자인·BGM·효과음 (2026-11-11)

## 변경 목적

v3.2의 실제로 검증한 클래식 퀴즈 진행·출제·자동 정답 공개·채점·점수·CSV·이미지 출제는 유지하고 **디자인만 중심으로 개선**했습니다.

### 새 기능

- 교사·학생 공통의 짙은 남색/보라색 아케이드 배경과 별빛 효과
- 문제 카드, 보기 4개(파랑/보라/노랑/하늘), 제출 버튼의 입체감 강화
- 정답 공개(초록), 오답(빨강)은 기존 의미 유지 + 시각 효과
- 문항별 남은 시간을 보여 주는 상단 진행 막대. 마지막 5초 강조
- 새 문제 시작 안내, 정답 맞힘 시 가벼운 종이 색종이 효과
- 결과 화면 1~3위 메달 표시, 최종 1~3위 시상대 표시
- 교사·학생의 큰 퀴즈 화면에서 `🔇 소리 켜기 / 🔊 소리 끄기` 토글
- **자체 제작 Web Audio 멜로디(BGM)** 및 선택·제출·정답·오답·시간 종료 전·최종 결과 효과음
- `prefers-reduced-motion` 사용자 설정을 고려해 애니메이션을 생략하는 동작

### 소리 동작과 중요한 안내

- 기본값은 **음소거**입니다. 크롬의 자동 재생 제한에 맞춰 각 기기에서 버튼을 한 번 눌러야 음악이 납니다.
- 소리는 각 학생 기기에서 별도로 설정됩니다. 교실 전체에 음악을 틀려면 **교사 컴퓨터만 켜서 스피커로 재생**하고 학생 기기는 음소거로 두는 편이 좋습니다.
- BGM은 브라우저의 Web Audio API에서 합성하는 짧은 오리지널 전자음 멜로디입니다. 블루킷의 음원을 복제하거나 사용하는 것이 아닙니다.
- 문제 출제 중에만 BGM을 재생하며 정답 공개/시상대에서는 음악을 일시 중단하고 효과음을 냅니다.
- 브라우저 설정 또는 기기 제약 때문에 소리가 재생되지 않을 수 있습니다. **소리가 안 나더라도 퀴즈 진행에는 영향이 없습니다.**

## GitHub 업로드

1. 기존 v3.2 저장소 상태를 보존합니다. GitHub의 이전 커밋으로 복원할 수 있습니다.
2. `quizlab-v3.3-upgrade.zip` 압축을 풉니다.
3. `https://github.com/slowjjb/classroom-quiz-lab`의 저장소 루트에서 **Add file → Upload files**를 누릅니다.
4. 압축을 푼 파일과 `js`, `tests` 폴더를 함께 올려 기존 파일을 덮어쓰고 **Commit changes**를 누릅니다.
5. GitHub Pages가 갱신된 후 `rooms.html`과 `join.html` 모두 **Ctrl+Shift+R**로 강력 새로고침합니다. QR 코드로 새로 열더라도 v3.3 표시를 확인합니다.

**Firebase 설정/규칙을 다시 변경하지 않습니다.** `firebase-config.js`와 `database.rules.json`은 업그레이드 ZIP에 포함되지 않습니다. 기존 문제 세트나 게임 기록을 삭제하거나 데이터 구조를 변경하지 않습니다.

## 실제 검증 (가상 학생 2명 권장)

1. `rooms.html`에서 **새 클래식 방**을 만들고 정상 CSV 20문항을 선택합니다.
2. 가상 학생 2명을 입장시킨 뒤 교사 화면에서 게임 준비 → 다음 문제 출제를 누릅니다.
3. **보기 색상·큰 문제 화면·시간 게이지**가 보이는지 확인합니다.
4. 학생 화면 우측 상단에서 소리를 켜고 **보기 선택 효과음과 BGM**을 확인합니다. 교사 기기는 필요할 때만 소리를 켜세요.
5. 학생 두 명이 서로 다른 답을 제출하여 **자동 정답 공개·정오답 표시·점수**가 정상적인지 확인합니다.
6. 결과 확인 화면에서 1~3위 메달을 확인하고, 마지막 문제 뒤 **최종 시상대**가 표시되는지 확인합니다.
7. 이미지가 있는 문제, 주관식 문제, 새 문제 보기 초기화, 학생 새로고침 복구도 기존과 동일한지 확인합니다.
8. 가상 학생 테스트가 실패하거나 교사 채점이 늦어지면 v3.2 커밋으로 복원한 뒤 원인을 확인합니다.
