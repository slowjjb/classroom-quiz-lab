퀴즈 실험실 v3.3 설치 안내
=======================================
1. quizlab-v3.3-upgrade.zip 압축을 풉니다.
2. https://github.com/slowjjb/classroom-quiz-lab 에 접속합니다.
3. Add file → Upload files 로 압축 해제한 파일 및 js, tests 폴더를 업로드합니다.
4. Commit changes 버튼을 누릅니다.
5. https://slowjjb.github.io/classroom-quiz-lab/rooms.html 열기
6. Ctrl + Shift + R 강력 새로고침 후 v3.3 표기 확인.
7. 학생용 join.html도 새 시크릿 창에서 v3.3 표기 확인.
8. 가상 학생 2명으로 문제 출제, 정답 공개, 결과, 시상대, 소리 기능을 점검합니다.

※ Firebase 보안 규칙 수정 불필요. 기존 학생 및 문제 세트 데이터 수정 불필요.
※ 소리 기본 OFF: 게임 화면 오른쪽 위 '소리 켜기' 버튼을 눌러야 재생합니다.
※ 반 학생들의 각 기기에서 소리를 켜면 시끄러울 수 있으므로 교사 컴퓨터만 ON 권장.
※ 전체 변경 내용과 오류 시 복구 방법은 README-v3.3.md 확인.
