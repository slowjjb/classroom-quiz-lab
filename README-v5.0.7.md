# 퍼플킷 v5.0.7 — 이미지 문항 좌우 배치

## 화면 변경
- 골드 퀘스트·피싱 프렌지에서 그림이 있는 문제만 **왼쪽 문제(40%) / 오른쪽 그림(60%)** 으로 표시합니다.
- 그림이 없는 문제는 기존 세로/중앙 배치로 표시합니다.
- 화면이 760px 이하인 학생 기기에서는 자동으로 세로 배치합니다.
- 그림은 원본 비율을 유지하며 `object-fit: contain`으로 표시합니다.
- 그림 주소가 잘못되었거나 로딩에 실패하면 피싱의 객관식 보기/주관식 입력은 정상 유지됩니다.
- 기존 v5.0.6의 교사 진행 상황, 이미지 오류 방어, 피싱 효과음 등 기능은 그대로 유지합니다.

## 업로드
- GitHub 저장소가 v5.0.6이라면 `purplekit-v5.0.6-to-v5.0.7-web-upload.zip` 파일의 압축을 풀고 **폴더 구조 그대로 GitHub에 덮어쓰기** 합니다.
- Firebase Realtime Database 규칙은 변경하지 않습니다.
- 교사와 학생 모두 게임방을 종료하고 새로 접속해 v5.0.7을 확인해 주세요.
- 같은 GitHub 저장소 최상위(`index.html`이 있는 위치)에 업로드합니다.

## 검증
- 이미지 포함/미포함 레이아웃, 작은 화면 CSS, Firebase 동기화 동작의 기존 테스트, 구문 및 웹 미리보기 검사.
- 교실의 실제 20~30명 동시 접속은 배포 후 검증이 필요합니다.
