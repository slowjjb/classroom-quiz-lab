# 퍼플킷 v3.12 — 문제 편집 화면 밀도·가독성 개선

## 변경 내용
- 각 문항에서 **원본 문항 번호(A) · 문제 유형(J) · 제한 시간(G)**을 한 줄에 배치합니다.
- 문제(B)와 보기/허용답(C~F) 입력창은 내용에 맞춰 높이가 자동 조정됩니다. 아주 긴 글은 일정 높이 이후 입력창 안에서 스크롤됩니다.
- 서로 다른 문항을 쉽게 구분하도록 **왼쪽 강조 테두리와 연한 제목 배경**을 네 가지 색상으로 순환합니다.
- 정답 보기 번호(H)의 입력 폭을 줄였습니다.
- 이미지가 없는 문항은 **문제 이미지 추가 (선택 사항)** 영역을 접어 둡니다. 저장된 이미지가 있는 문항은 기존처럼 열어서 확인할 수 있습니다.
- 문제 유형을 변경했을 때 현재 문항이 접혀 버리지 않도록 보정했습니다.
- 메인·학생·교사·문제 관리 페이지에 표시되는 버전 표기를 v3.12로 맞췄습니다.

## 기존 데이터 보호
- `firebase-config.js`, `database.rules.json`을 수정하지 않습니다.
- CSV A~J 10열 형식, Firebase 문제 세트 경로 및 채점 로직을 변경하지 않습니다.
- GitHub 업로드 전 현재 저장소에서 ZIP 백업을 하나 내려받거나 기존 커밋을 기록하세요.

## 적용 방법
1. `purplekit-v3.12-upgrade.zip` 압축을 풉니다.
2. 압축을 푼 폴더 **내부 파일과 `js` 폴더**를 GitHub 저장소 최상위로 업로드합니다. 폴더 자체를 새 하위 폴더로 만들지 마세요.
3. 기존 파일에 대한 덮어쓰기를 확인하고 `Commit changes`를 누릅니다.
4. GitHub Pages 배포가 끝나면 `https://slowjjb.github.io/classroom-quiz-lab/sets.html`에서 `Ctrl+Shift+R`로 강력 새로고침합니다.
5. 3~4문항을 펼쳐 문제·보기 높이, 유형 변경, Firebase 저장 및 다시 불러오기를 확인합니다.
