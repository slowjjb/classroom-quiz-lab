# 퍼플킷 v4.10 — 골드 손실 완화 및 당첨 보상 강조

## 변경 사항
- 17종 보상은 유지하고 가중치를 2,000칸(1칸=0.05%)으로 변경했습니다.
- 손실 10% 보상 확률: 10% → 8%.
- 손실 50% 보상 → 손실 30% 보상. 출현 확률: 5% → 3%.
- 전부 잃기: 0.1% → 0.05%.
- 줄어든 4.05%p: +10G 10→12%, +20G 13→14%, +35G 12→13%, +250G 1.7→1.75%로 배분했습니다.
- 나머지 보상 10종의 당첨 확률은 그대로이며 총합은 정확히 100%입니다.
- 학생이 상자를 열면 어떤 상자(1~3번)를 골랐는지와 당첨된 보상 종류(예: `내 골드 30% 잃기!`)를 매우 크게 표시합니다.
- 그 아래에서 실제 골드 증감과 적용 결과, 보유 골드를 별도로 보여줍니다.
- 연출 시간은 3초에서 3.8초로 소폭 늘렸으며 `다음 문제로 계속하기` 버튼은 유지합니다.
- 세 상자는 동일한 확률입니다. 학생 직접 상대 선택, 보기 순환, 정답률 분석 및 골드 지급 트랜잭션은 변경하지 않았습니다.
- 교사용 전광판 확률표는 변경된 보상 데이터를 자동 반영합니다.

## 설치
1. v4.10 업그레이드 ZIP을 압축 해제하고 `GitHub > classroom-quiz-lab` 저장소에 내용을 업로드합니다.
2. `Commit changes` 후 GitHub Pages 배포 완료를 확인합니다.
3. 교사 `rooms.html`, 학생 `join.html`에서 캐시 무시 새로고침 후 `v4.10` 버전을 확인합니다.
4. **진행 중인 게임이 완전히 끝난 후 업데이트**하세요. 새로 출제되는 상자부터 바뀐 확률을 사용합니다.

## 데이터 / Firebase
- Firebase Realtime Database 규칙을 변경할 필요가 없습니다. v4.8 이후 규칙을 유지합니다.
- 기존 문제 세트와 누적 학습 기록, 골드 보상 지급 방식은 변경하지 않습니다.
- 저장된 이전 보상 기록은 소급 변경되지 않습니다.
