# 퍼플킷 v5.0.8 — 피싱 프렌지 바다 생물 도감 & 연출

## 주요 개선
- 23종 도감을 왼쪽 12종(2×6), 오른쪽 11종(2×6)으로 배치합니다.
- 미발견 생물은 각 원본의 검은 실루엣이며, 잡으면 색상·이름·최고 무게(kg)를 표시합니다.
- 같은 어종을 다시 낚으면 최고 무게만 갱신합니다. ‘어린 상어’도 상어의 기록으로 기록됩니다.
- 기록은 기존 `v5/public/게임방코드/scores/학생UID/bestBySpecies` 안에 저장됩니다. 한 게임의 재접속에는 남고 **새 게임방을 준비하면 초기화**됩니다.
- 추가 Firebase 구독은 없습니다. 교사의 기존 정답 처리 트랜잭션에서 함께 반영합니다.
- CAST 릴/물보라, HIT 알림/파도, 낚싯대 파손, 전설 획득 효과음과 애니메이션을 추가했습니다.
- 소리 켜기/끄기 버튼은 기존 설정을 유지합니다. 자동재생 제한으로 최초 학생 클릭 이후 소리가 재생될 수 있습니다.
- 가로 공간이 좁은 기기에서는 문제를 우선 표시하고 도감을 접기/펴기로 전환합니다.
- 원본 스프라이트는 수정하지 않았고 작은 WebP 썸네일 23개(합계 약 180KB)를 새로 생성했습니다.

## 업로드 방법
1. GitHub 저장소가 이미 v5.0.7이면 `v5.0.7-to-v5.0.8` 변경 파일 ZIP을 압축 풀어 루트에 덮어쓰세요.
2. ZIP 파일 자체를 업로드하는 것이 아니라 **압축 해제한 파일과 폴더**를 올려야 합니다.
3. `index.html`이 저장소 최상위에 있어야 합니다. `classroom-quiz-lab-main/`을 한 번 더 만들지 마세요.
4. `version.json` 및 `js/version.js`가 둘 다 5.0.8 / build 508인지 확인하세요.
5. 교사/학생 모두 이전 탭을 닫고 새 게임방에 입장하세요. Firebase 통합 규칙은 기존 v5 규칙 그대로 사용합니다.
6. 먼저 `fishing-demo.html`을 열어 도감/효과음을 테스트할 수 있습니다.

## 검증 범위
로컬 자동 테스트 및 브라우저 UI/시뮬레이션 테스트가 가능하며, 실제 Firebase 20~30명 동시 접속/장시간 수업 안정성은 별도 검증이 필요합니다.
