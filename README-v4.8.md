# 퍼플킷 v4.8 — 골드 퀘스트 전광판 및 상대 직접 선택

기반 버전: v4.7. 기존 문제 세트, 보상 17종과 각 보상의 확률, 정답 판정, Firebase 데이터는 유지합니다.

## 달라진 기능

1. 교사 골드 퀘스트 전광판 왼쪽에 1~3위의 이름과 보유 골드를 큰 카드로 표시합니다. 오른쪽 실시간 순위는 기존과 동일합니다.
2. 교사 전광판 왼쪽 아래에 17종 보물상자 보상 확률표를 표시합니다. 참가자 수가 1명이거나 공격 보상을 끈 경우에는 실제 적용되는 확률로 재정규화합니다.
3. 교사 준비 설정에 '빼앗기·교환 상대 결정 방식'을 추가합니다. 기본값은 **무작위 선택**으로 기존 동작을 유지합니다. **학생이 직접 선택**을 고른 새로운 방에서는 빼앗기 또는 교환 보상이 발생한 학생에게 15초 동안 대상 선택 화면을 띄웁니다. 시간 내 선택하지 않으면 무작위로 결정합니다. 자기 자신은 대상에서 제외됩니다.
4. 학생 선택 대상은 교사가 보상 결과를 먼저 확정한 이후에만 선택할 수 있습니다. 실제 골드 증감은 Firebase 트랜잭션으로 보상당 한 번만 적용하도록 유지합니다.
5. 기존 v4.7 방에서는 선택 기능을 요구하지 않습니다. 기존 v4.7 보상·문항 데이터와 호환됩니다.

## 설치

1. `purplekit-v4.8-upgrade.zip`을 압축 해제하고, 그 안의 파일과 폴더를 GitHub 저장소의 최상위 폴더에 기존 파일과 **덮어쓰기**로 업로드합니다. ZIP 자체를 올리지 마세요.
2. GitHub Pages 배포 완료 후 교사용 `rooms.html`과 학생용 `join.html`을 모두 새로고침합니다. 상단의 `v4.8` 표기를 확인합니다.
3. **학생 직접 선택을 사용하려면** 교사용 화면의 `Firebase 보안 규칙 복사/다운로드` 버튼으로 `v4.8` 전체 규칙을 생성해 Firebase Console > Realtime Database > 규칙에 게시합니다. `database.rules.json` 파일을 GitHub에서도 따로 관리 중이라면 같은 규칙으로 업데이트해야 합니다. 교사 Google 로그인 UID를 반영한 규칙이므로 ZIP에 공통 고정 규칙 JSON은 포함하지 않았습니다.
4. 기존의 무작위 선택 및 전광판 기능만 사용한다면 종전 v4.7 Firebase 규칙을 사용해도 됩니다.
5. 새 게임 방을 만들고 `보물찾기 준비` 전에 상대 선택 방식을 설정합니다. 설정은 게임 준비 시 해당 방에 저장됩니다.

## 주의 사항

- 학생 직접 선택은 교사가 허용한 새 방에서만 적용됩니다. 특정 학생이 집중적으로 지목될 수 있으니 학급 상황을 고려해 주세요.
- 선택 대기 중에도 전체 게임 제한 시간은 흐릅니다. 게임이 끝날 때 아직 대기 중인 보상이 있다면 교사 화면에서 무작위 상대를 정해 처리하도록 했습니다.
- 게임 운영 중 **교사용 브라우저를 열어 두세요.** 보상 추첨과 골드 트랜잭션은 교사 브라우저에서 처리합니다.
- 현재 버전은 로컬 자동 테스트 및 브라우저 레이아웃 점검을 수행했습니다. 실제 교실의 Firebase/디벗 20명 동시 접속 검증까지 완료한 것은 아닙니다.
