# 퀴즈 실험실 v3.5 — 좌우 하단 정렬·콘텐츠 높이 균형 개선

v3.4에서 확인된 실제 학생·교사 화면을 기준으로 **레이아웃 CSS만** 수정했습니다.
Firebase 인증/정답 판정/점수/참여자 데이터는 변경하지 않았습니다.

## 바뀐 화면

- 학생 대기실 (가로 900px 이상): 왼쪽 제목+참여 코드/이름 영역과 오른쪽 방 이름/친구 명단 영역의 하단 경계선이 같도록 자동 높이 맞춤. 친구 20~25명은 넓은 화면에 여러 열로 표시. 그보다 많아지면 이름 목록만 내부 스크롤하도록 제한.
- 학생 문제 풀이 (가로 760px 이상, 화면 높이 540px 이상): 왼쪽 정보바와 오른쪽 문제/보기/제출 영역의 전체 높이를 동일하게 맞춤. 문제 카드가 늘어나 짧은 문제도 여백을 차분하게 활용하고, 정답 공개 뒤 `결과 확인 · 친구들 순위 보기` 버튼은 오른쪽 맨 아래 위치.
- 교사 집중 화면 (가로 760px 이상): 왼쪽 진행 정보+음량/조작 영역의 합계 높이를 오른쪽 문제+보기 영역의 높이와 정렬. 그림이 없는 문제도 문제 카드를 높이 확장하여 빈 배경 공간이 덜 보이게 구성.
- 작은 모바일 화면에서는 기존 세로형 방식을 그대로 적용. 화면 크기가 작거나 글이 매우 길면 내용이 잘리는 대신 스크롤 허용.

## 설치

1. 현재 GitHub 저장소의 v3.4 상태를 백업합니다.
2. **`quizlab-v3.5-upgrade.zip`** 압축을 풉니다.
3. 압축 해제된 파일(`join.html`, `rooms.html`, `index.html`, `sets.html`, `responsive-v3.5.css`)을 GitHub 저장소 루트에 업로드하고 Commit changes.
4. 배포가 완료되면 교사 `rooms.html`, 학생 `join.html`에서 Ctrl+Shift+R로 새로고침합니다.
5. 학생 입장 화면과 클래식 문제/정답 공개 화면의 하단 정렬을 확인합니다.

**Firebase 보안 규칙과 `firebase-config.js`는 변경하지 않습니다.** 업그레이드 ZIP에 포함되지 않습니다.

## 테스트

`node tests/test-v3-4.mjs`, `node tests/test-v3-4-runtime.mjs` 등 기존 검사 및 Playwright 반응형 스크린샷 검사로 확인합니다. 실제 학교 디벗과 Firebase 접속은 배포 후 확인해 주세요.
