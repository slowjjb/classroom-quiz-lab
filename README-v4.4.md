# 퍼플킷 v4.4 — CSV 이미지 일괄 연결

v4.3을 기반으로, 기존 게임 기능을 수정하지 않고 **문제 세트 관리(sets.html)**의 CSV 이미지 연결만 확장했습니다.

## 두 가지 CSV 양식 (고정 기준)

| 열 | 블루킷 | 퍼플킷 |
|---|---|---|
| A | 1부터 연속되는 문항 번호 | 동일 |
| B | 문제 내용 | 동일 |
| C~F | 객관식 보기 1~4 / 주관식 허용 답 | 동일 |
| G | 제한 시간(초) | 동일 |
| H | 객관식 정답 번호 1~4 / 주관식은 공란 | 동일 |
| I | 항상 공란 | 동일 |
| J | 주관식일 때 정확히 `typing`, 객관식은 공란 | 동일 |
| K | **없음: 반드시 A~J 10열** | **이미지 파일이 필요한 세트에만 추가** |

- **블루킷 CSV**: 무조건 10열(A~J). 예전 자료와 100% 동일한 구조.
- **퍼플킷 CSV**: 이미지가 한 문제라도 있으면 11열(A~K), 나머지 문항의 K열은 공란으로 둡니다. 이미지가 하나도 없으면 10열(A~J)을 사용합니다.
- K열에는 `도형_005.png`처럼 파일명만 입력합니다. 한글 파일명을 지원합니다.
- CSV 첫 줄 제목 행은 없어도 됩니다. 기존 헤더 인식 기능은 유지됩니다.
- 기존 10열 CSV를 그대로 가져올 수 있습니다.

## 이미지 연결 순서

1. 이미지 파일 여러 개를 GitHub 저장소의 `images/questions/` 폴더에 업로드하고 `Commit changes`합니다. **퍼플킷 앱이 GitHub에 이미지를 업로드하는 것은 아닙니다.**
2. GitHub Pages 배포가 끝나면 **문제 세트 관리**에서 CSV를 선택합니다.
3. 이미지가 있는 경우 K열을 읽어 `images/questions/<파일명>`으로 자동 연결합니다. 파일 이름은 정확히 일치해야 하며, 대소문자를 구별합니다.
4. 화면에 **이미지 연결 성공 / 파일 없음(404) / 확인 불가(네트워크 오류, 접근 제한 등) / 이미지 없음**이 표시됩니다.
5. 필요하면 **이미지 파일 다시 확인** 버튼을 누릅니다.
6. 수정이 필요하면 해당 문제의 이미지 필드를 직접 변경할 수 있습니다.
7. 확인 결과와 관계없이, CSV 문항 자체가 정상이라면 Firebase에 저장할 수 있습니다. 파일 누락은 별도 경고로 제공합니다.

## 내보내기

- **퍼플킷용 CSV**: 이미지가 있는 문제 세트는 11열, 이미지가 없는 문제 세트는 10열로 자동 저장합니다. Firebase에 저장된 이미지 경로는 URL 대신 읽기 쉬운 파일명으로 K열에 나갑니다.
- **블루킷용 CSV**: 항상 10열로 저장합니다. 이미지가 있는 세트를 내보낼 때 K열이 제외된다는 확인 안내가 나타납니다.
- 모든 CSV는 UTF-8 BOM을 포함합니다.

## 설치 (v4.3 → v4.4)

1. `purplekit-v4.4-upgrade.zip`을 풀어 폴더 **안의 파일/폴더**를 `https://github.com/slowjjb/classroom-quiz-lab` 저장소 최상위에 업로드합니다. 압축파일 자체를 업로드하지 마세요.
2. GitHub `Commit changes`를 누르고 Pages 배포를 확인합니다.
3. `https://slowjjb.github.io/classroom-quiz-lab/sets.html`에 접속해 `Ctrl + Shift + R`로 새로고침합니다.
4. 기존 블루킷 CSV와 퍼플킷 K열 CSV를 각각 한 번씩 시험해 보세요.

**Firebase 보안 규칙 변경: 필요 없음.** `firebase-config.js`, `database.rules.json`, 캐릭터 이미지, 기존 문제 세트 데이터는 업그레이드 ZIP에 포함하지 않습니다.
