# 퍼플킷 v4.0 — 골드 퀘스트 첫 테스트판

## 새 기능
- 클래식과 독립적으로 실행되는 **골드 퀘스트** (mode=gold)
- 학생별 개별 문제 순서 (셔플백, 최근 10문항 중복 회피; 문항 수가 작으면 가능한 만큼 회피)
- 객관식·주관식 및 문제 이미지 지원
- 정답 시 3개의 보물상자 중 하나 선택
- 보상: 골드, 큰 보너스, 소액 훔치기, 골드 차이 20% 이내의 제한적 교환, 잭팟
- 교사 설정: 3·5·7·10·15분, 훔치기·교환 허용/해제
- 실시간 학생/교사 골드 순위, 최종 시상대, CSV 결과 내보내기
- 골드 퀘스트 전용 오리지널 모험 BGM 2곡
- 학생은 보물/정답만 제출, 채점·골드 보상은 교사 브라우저에서 실행

## 반드시 알아두기
**이 버전은 정적·모의 화면 테스트를 통과한 첫 테스트판입니다.** 실제 Firebase 연결에서 다수 학생의 동시 답안·보상 처리는 아직 검증하지 않았습니다. 먼저 2~3개 기기로 시범 운영하세요.

교사 브라우저가 채점/보상을 수행합니다. **골드 퀘스트 중 교사 탭을 닫지 말고, 한 방을 두 개 이상의 교사 탭에서 동시에 진행하지 마세요.** 교사 탭을 닫으면 새 답안과 보상이 멈출 수 있으며, 다시 열면 보관된 요청을 이어서 처리하려고 합니다. 이번 버전은 별도의 서버/Cloud Functions를 사용하지 않습니다.

게임 종료 이전에 이미 제출된 결과가 네트워크 지연으로 늦게 도착할 수 있습니다. 교사가 종료 후 CSV를 내보내기 전에 순위가 안정화되는지 확인해 주세요.

## GitHub Pages 업그레이드
1. `purplekit-v4.0-upgrade.zip`을 다운로드해 **압축을 풉니다**.
2. GitHub `slowjjb/classroom-quiz-lab` → `Add file` → `Upload files`.
3. 압축 폴더 안의 `index.html`, `rooms.html`, `join.html`, `gold.css` 등과 `js/`, `tests/` 폴더를 **저장소 최상위에 업로드**합니다. ZIP 자체를 업로드하지 마세요.
4. `Commit changes`로 저장합니다. `firebase-config.js`, 기존 아바타 이미지, 기존 데이터는 교체/삭제하지 않습니다.
5. Pages 배포가 완료되면 `Ctrl+Shift+R`로 강력 새로고침합니다.

## Firebase Realtime Database 규칙 — 이번 버전에서 반드시 새로 게시
1. `https://slowjjb.github.io/classroom-quiz-lab/rooms.html` 로그인.
2. 문제 세트 선택 후 **게임 모드: 골드 퀘스트** 선택, 새 방 생성.
3. 아래 **v4 권한 설정**의 `v4 전체 보안 규칙 복사` 버튼 클릭. 교사 UID가 자동 포함된 규칙입니다.
4. Firebase 콘솔 → Realtime Database → **규칙(Rules)** → 전체 붙여넣기 → **게시**.
5. 같은 화면에서 `v4 규칙 JSON 다운로드`를 누르면 `database.rules.json`을 보관할 수 있습니다. GitHub 저장소에도 동일한 규칙 파일을 보관하는 것을 권장합니다.
6. 규칙 게시 후 교사/학생 화면 `Ctrl+Shift+R`.

규칙은 과거 v0~v3.8 기능을 그대로 포함하고, 새로운 `v4/` 경로만 추가합니다. 과거 규칙을 수동 수정했다면 게시 전에 반드시 비교하세요.

## 시작 순서
1. `sets.html`에서 문제 세트를 등록/저장합니다. 기존 세트를 그대로 사용할 수 있습니다.
2. `rooms.html`에서 새 게임 방 생성: **골드 퀘스트**, 문제 세트, 방 이름 선택.
3. 학생이 `join.html`에서 참여 코드와 이름으로 입장하고 캐릭터를 선택합니다.
4. 교사 화면의 골드 퀘스트 패널에서 게임 시간 및 공격형 보상 허용 여부를 설정합니다.
5. `보물찾기 준비·입장 마감` → `골드 퀘스트 시작` → `순위 전광판 열기`.
6. 학생은 각자 다른 문제를 풀고 정답 시 보물상자를 고릅니다.
7. 시간이 끝나거나 교사가 종료하면 최종 골드 순위가 표시됩니다.
8. **골드 결과 CSV**로 기록을 내려받은 뒤, 필요하면 방 종료/삭제를 진행합니다.

## 데이터 / 보안 경로
- `v4/privateRuns/<code>` — 교사 전용 문제·정답·셔플덱·기록
- `v4/public/<code>` — 참가 학생에게 공개되는 게임 상태·점수
- `v4/memberState/<code>/<uid>` — 해당 학생/교사만 읽는 개별 문제
- `v4/answers/<code>/<uid>/<nonce>` — 학생의 1회 답안 제출
- `v4/picks/<code>/<uid>/<nonce>` — 학생의 1회 보물 선택

## 현재 제한과 다음 검증
- 한 문제의 별도 제한시간 대신 **전체 게임 시간 제한**을 사용합니다.
- 보물상자 결과는 교사 권한에서 랜덤하게 결정합니다. 선택한 상자마다 고정된 보상이 미리 배치되는 방식은 아닙니다.
- 훔치기/교환은 학급 갈등을 줄이기 위해 **소액/일부 차이만 이동**합니다.
- 답안 제출·시상대 표시·재접속·20~30명 동시 보상 처리·실제 스피커 음량을 별도 테스트해야 합니다.
- 학생 골드는 학급은행과 아직 연결되지 않습니다.
