# 퍼플킷 v4.9 — 학생용 종료 학습 분석 및 학생 정답률 내림차순

기반 버전: v4.8. 골드 퀘스트 보상 확률, 학생 상대 선택, 보기 섞기, 채점, CSV 문제 관리, 클래식 모드는 변경하지 않았습니다.

## 변경 사항

1. 교사용 골드 퀘스트 종료 화면의 **학생별 정답률을 높은 순 → 낮은 순**으로 정렬합니다. 정답률이 같은 경우 이름의 가나다순이며 기록이 없는 학생은 맨 아래에 '—'로 표시됩니다.
2. 학생용 골드 퀘스트 **게임 종료 화면**에 **학생별 정답률**과 **문항별 정답률**을 추가합니다. 학생별 정답률은 높은 순, 문항별 정답률은 문제 번호순으로 정렬합니다. 본인 행을 강조합니다.
3. 학생은 `첫 시도`(문항별 최초 답안)와 `전체 시도`(반복 제출 포함)를 전환할 수 있습니다. 골드 순위와 별개의 학습 기록임을 안내합니다.
4. 교사 브라우저가 게임을 종료할 때 최종 채점 로그를 읽고 **정답 개수·풀이 개수·정답률만 집계**하여 `v4/public/<room-code>/learningResults`에 일회성으로 게시합니다. 학생에게 정답 원문/정답 번호/학생별 원본 제출 기록은 공개하지 않습니다.

## 설치 및 운영

- `purplekit-v4.9-upgrade.zip` 압축 해제 후 그 안의 파일/폴더를 기존 GitHub 저장소 **최상위에 덮어쓰기**로 올립니다. ZIP 파일 자체를 업로드하지 마세요.
- GitHub Pages 배포 후 교사 `rooms.html`과 학생 `join.html`을 강력 새로고침하고 둘 다 `v4.9`인지 확인합니다.
- **v4.8 Firebase Realtime Database 보안 규칙 그대로 사용합니다.** 새로운 규칙이나 추가 서비스가 필요하지 않습니다.
- 이 기능은 **v4.9 설치 후 새로 종료하는 골드 퀘스트 게임부터** 작동합니다. 이미 종료된 v4.8 방은 자동 분석 공개 데이터를 보유하지 않으므로 학생에게 새 표가 보이지 않습니다.
- 각 학생에게 다른 학생들의 이름과 정답률이 공개됩니다. 학급 운영상 민감하다면 전체 공개 전에 반의 운영 원칙을 검토하세요.
- 교사 브라우저를 열어 둔 채 종료 버튼 또는 자동 타이머 종료를 정상 처리해야 학생 분석 데이터가 게시됩니다.
