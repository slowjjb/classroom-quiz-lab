퍼플킷 v3.11 — GitHub 업로드 안내
========================================

이 버전은 v3.9 → v3.11 직접 업그레이드가 가능합니다.
기존에 v3.10을 업로드하지 못했어도 이 ZIP 하나만 적용하면 됩니다.

[1] 업그레이드 ZIP을 다운로드하고 압축을 풉니다.
[2] https://github.com/slowjjb/classroom-quiz-lab 접속 → main 브랜치를 확인합니다.
[3] Add file → Upload files를 클릭합니다.
[4] 압축 해제한 폴더 '안에 있는 파일과 js 폴더'를 업로드 영역에 드래그합니다.
    저장소 최상위에 index.html, join.html, rooms.html, sets.html 등이 있어야 합니다.
    js/sets.js는 반드시 js 폴더 안에 있어야 합니다.
    별도의 purplekit-v3.11-upgrade 폴더가 GitHub에 새로 생기면 안 됩니다.
[5] Commit changes를 클릭합니다.
[6] GitHub Pages 배포 완료 후 다음 주소를 열어 확인합니다.
    - 메인:  https://slowjjb.github.io/classroom-quiz-lab/
    - 교사:  https://slowjjb.github.io/classroom-quiz-lab/rooms.html
    - 문제:  https://slowjjb.github.io/classroom-quiz-lab/sets.html
    - 학생:  https://slowjjb.github.io/classroom-quiz-lab/join.html
    - 브라우저 강력 새로고침: Ctrl + Shift + R

기존 firebase-config.js, database.rules.json, images/, 기존 다른 JS 파일은 덮어쓰거나 삭제하지 마세요.
이번 업데이트에는 Firebase 보안 규칙·문제 데이터 변경이 없습니다.

[간단한 점검]
- 모든 화면의 상단에 퍼플킷 v3.11이 표시되는가?
- 문제 세트 관리: 왼쪽 인증/저장 목록, 오른쪽 CSV/문항 편집이 보이는가?
- 게임 방 관리: 왼쪽 인증, 오른쪽 방 생성/목록이 보이는가?
- 학생 입장: 코드+이름, 캐릭터, 친구 목록이 표시되는가?
- 가상 학생 2명으로 문제 풀이/정답 공개/결과 확인을 진행할 수 있는가?

문제가 있다면 GitHub에서 이전 커밋으로 돌아가 v3.9를 복구할 수 있습니다.
