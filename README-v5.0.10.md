# 퍼플킷 v5.0.10 (피싱 프렌지 교사 화면 개선)

- 피싱 교사 전광판: 게임 종료 시 골드 퀘스트형 1~3위 시상대가 보입니다. 아바타·누적 무게(kg)를 표시합니다. 분석표와 결과 CSV 기능은 유지했습니다.
- 시상대 접기/펼치기로 정답률 결과표를 더 넓게 볼 수 있습니다.
- 피싱 벌칙 재발동 최소 간격을 **60초 → 30초**로 줄였습니다. **확률 4.5%**, **효과 지속시간 2.7초**는 그대로입니다. 벌칙이 정확히 30초마다 자동 발생하는 것은 아닙니다.
- 피싱 방에서는 클래식 진행 패널을 숨깁니다. 골드·클래식 방도 각자 해당 패널만 표시합니다.
- 게임 판정, Firebase 규칙, 기존 정답률 계산은 변경하지 않았습니다.

## GitHub 적용

GitHub 웹 업로드용 ZIP을 압축 해제한 다음 저장소 루트에 파일과 폴더를 **동일한 경로로 덮어쓰기**하세요. 전체 프로젝트 ZIP에는 `classroom-quiz-lab-main/` 최상위 폴더가 있습니다.
학생과 교사 모두 새 탭으로 입장하여 버전 표시를 확인하세요. Firebase 보안 규칙 변경은 필요 없습니다.
