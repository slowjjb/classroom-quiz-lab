# 퍼플킷 v5.0 — 피싱 프렌지 (2026-11-16)

**v4.12 전체 프로젝트 기반에 v5 신규 게임 모드를 추가한 통합본입니다.** 기존 클래식, 골드 퀘스트, 문제 세트, 아바타 기능을 삭제하지 않았습니다.

## 포함 기능

- 방 생성에서 **피싱 프렌지** 선택 → 기존 문제 세트 연결 → 학생 대기실 → 교사 준비·게임 시작·종료
- 학생: 낚싯대 투척(CAST) → 서버가 정한 1~3초 입질 대기 → HIT 클릭 → 객관식/주관식 풀이 → 바다 생물·무게(kg) 확인
- 오답: 물고기를 놓치고 내구도 1 감소. 내구도 5에서 0이 되면 낚싯대가 부러지고 루어 Lv.1/내구도 5로 복구, **총 kg은 유지**
- 루어: Lv.1~3은 일반 정답 3개, Lv.4~6은 4개, Lv.7+은 5개 뒤 **다음 낚시가 강화 문제**. 강화 문제 정답일 때만 단계 +1. 강화 오답은 정답 1~3개 후 같은 단계 재도전. **상한 없는 단계 성장**
- 내구도 회복: 첫 버전은 **없음(0)**. 실사용 후 `js/fishing-core.js`의 `FISHING_LURE_HEAL`을 1로 바꿀 수 있음
- 무게: Lv.1~8은 단계별 지정 범위, 이후 2차식으로 상한 없이 확장. 무거운 물고기는 상대적으로 드문 분포 사용
- 전설 생물: **Lv.5부터** 등장 (Lv.5 1%, Lv.6 2%, Lv.7 4%, Lv.8 7%, Lv.9 10%, Lv.10 12%, 이후 최대 15%)
- 23종 바다 생물: 일반 8, 대형 5, 희귀 5, 전설 5. 사용자가 승인한 고해상도·귀여운 픽셀아트 콘셉트 시트에서 스프라이트로 분리
- 벌칙: 일반 낚시 정답의 3% 추첨, 발동자를 뺀 같은 게임방의 학생 화면에 **약 1.8초 시각적 방해**, 동일 방 **60초 전역 쿨타임**. 이미 획득한 무게는 빼앗지 않음. 화면의 정답 버튼은 잠시 가려질 수 있지만 클릭을 차단하지 않음
- 교사 인증 브라우저가 정답·무게·강화·벌칙을 계산하고 Firebase에 저장. 점수 기록은 Firebase 트랜잭션으로 중복 제출 방지
- 새로고침 후 학생 낚시 단계(캐스팅·입질·문제·결과) 및 점수 복구

## 설치 순서 — 실제 배포 전 꼭 읽으세요

1. **현재 작동하는 v4.12 전체 프로젝트와 Firebase 규칙을 따로 백업**합니다.
2. 이 패키지의 `fishing-demo.html`을 **더블클릭해서** 오프라인 시연으로 낚시 화면과 보상 연출을 먼저 확인할 수 있습니다. 이 화면은 Firebase와 연결되지 않는 시험용입니다.
3. Firebase Realtime Database → **규칙**에 **v5 전체 통합 규칙**을 게시합니다. 로그인한 교사의 **`rooms.html` → 교사 인증 → v5 전체 규칙 복사** 기능으로 복사하는 것을 권장합니다. `database.rules.json`도 동일한 규칙을 보관하는 파일입니다. **v4 규칙으로 다시 덮어쓰면 v5 학생 쓰기가 막힙니다.**
4. 압축파일 안의 **프로젝트 전체 파일을** GitHub 저장소에 반영하여 GitHub Pages를 배포합니다. 하위 폴더 구조를 유지해야 이미지와 JS 모듈이 로드됩니다.
5. 교사 계정 로그인 → `rooms.html` → `피싱 프렌지` 선택 → 문제 세트 선택 → 새 방 만들기. 학생 2~3명을 먼저 연결하여 교사 화면을 연 채 준비 → 시작합니다.
6. **CAST → HIT → 문제 → 결과 → 다음 낚시**, 오답·루어 강화·새로고침·벌칙, 타이머 종료와 결과 CSV를 확인합니다. 이후 전체 반 테스트로 확대하세요.

## 기술 및 주의사항

- 버전 `APP_VERSION=5.0`, `APP_BUILD=500`, `version.json=500`. 이전 학생 창은 버전 확인 후 업데이트가 필요합니다.
- v4.12 기존 방/데이터/문제 기록과 v5의 경로를 분리했습니다: `v5/privateRuns`, `v5/public`, `v5/memberState`, `v5/actions`, `v5/answers`.
- 모든 v5 무게·벌칙·정답 판정은 교사 로그인 화면에서 실행합니다. **교사 화면을 닫으면 처리되지 않으며**, 독립 서버(Cloud Functions) 방식은 추후 개선 과제입니다.
- Firebase 규칙 게시, 실제 학생 기기 동기화, 30명 동시 접속 및 장시간 실전 검증은 이 개발 환경에서 수행하지 못했습니다. 이 패키지는 **실사용 전 시험이 필요한 신규 버전**입니다.
- 방 전체 벌칙은 교사 화면 트랜잭션에서 60초 간격으로 하나만 확정됩니다. 교사 서버 시계 보정 기반이며 학생 기기의 실제 시각은 네트워크 지연으로 수백 ms 차이가 날 수 있습니다.
- 바다 생물별 실제 생물학적 무게는 정확히 재현하지 않고 게임 밸런스를 우선합니다. 고래나 모사사우루스 등도 바다 생물 컬렉션으로 표현합니다.
- `fishing-demo.html`은 혼자 체험하는 규칙 시뮬레이터이므로 단체 벌칙 전송을 실제로 구현하지 않습니다. 게임방에서는 Firebase로 전달됩니다.
