# 퍼플킷 v4.1 — 골드 퀘스트 시작/규칙 안내 오류 수정

## 이번 버전에서 고친 오류
1. **v4 규칙 미게시 시 골드 퀘스트 패널 전체가 숨겨지는 문제 수정.**
   - 기존 v2 대기실 권한으로 방의 게임 모드를 먼저 확인합니다.
   - v4 권한 검사가 실패하더라도 골드 퀘스트 패널과 보안 규칙 복사·JSON 다운로드가 나타납니다.
2. **v4 규칙을 게시한 뒤 페이지를 새로 만들 필요 없이 '권한 다시 확인'으로 재검사.**
3. 교사 방 데이터를 아직 받기 전 렌더링 순서에 따라 발생할 수 있던 null 접근 오류 수정.
4. 기존 방 코드 유지 및 '골드 퀘스트 설정으로 이동' 안내 링크 추가.
5. 학생이 v4 데이터를 읽지 못할 때 대기실에 오류 메시지를 표시.
6. 보안 규칙 복사 버튼의 과거 v3.8 표기와 다운로드 파일명을 정리.

## GitHub 업그레이드 설치
1. `purplekit-v4.1-upgrade.zip`을 풀어 안에 있는 파일과 `js` 폴더를 저장소 최상위에 업로드합니다.
2. GitHub `slowjjb/classroom-quiz-lab` → Add file → Upload files → Commit changes.
3. `https://slowjjb.github.io/classroom-quiz-lab/rooms.html` 을 Ctrl+Shift+R로 새로고침합니다.
4. 기존 골드 퀘스트 방을 선택해 아래쪽 `💎 v4.1 골드 퀘스트` 패널을 엽니다.
5. `v4 전체 보안 규칙 복사` 클릭 후 Firebase 콘솔 → Realtime Database → 규칙에 전체 붙여넣기 → 게시.
6. 프로그램으로 돌아와 `권한 다시 확인`을 누릅니다. 성공하면 `보물찾기 준비·입장 마감` 버튼이 활성화됩니다.
7. 학생이 1명 이상 입장한 상태에서 `보물찾기 준비·입장 마감` → `골드 퀘스트 시작`을 누르세요.
8. 학생용 `https://slowjjb.github.io/classroom-quiz-lab/join.html`에서 문제와 상자 선택을 확인하세요.

### 주의
- 기존 Firebase `firebase-config.js`, 학생 프로필, 문제 세트, 아바타 이미지, 클래식 데이터는 변경하지 않습니다.
- 이번 **v4.1 업그레이드는 GitHub 업로드 외에 실제 Firebase 보안 규칙 게시가 필요**합니다.
- 현재 방(학생 이름 예약, 참여 코드)은 삭제할 필요가 없습니다. 게임 시작 전에는 입장 마감 상태를 확인하세요.
- 기존 Firebase 규칙을 수동 변경한 적이 있다면 생성된 통합 규칙과 비교 후 게시하세요.
- Gold Quest v4는 첫 테스트판으로, 실제 교실 20명 동시 보상 지급은 아직 검증되지 않았습니다.
- 골드 퀘스트 채점·골드 계산은 **교사 브라우저에서 실행**하므로 게임 중 교사 탭을 계속 열어 두고, 같은 방을 교사 탭 2개에서 동시에 실행하지 마세요.
