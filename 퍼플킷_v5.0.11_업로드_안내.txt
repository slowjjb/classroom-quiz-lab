퍼플킷 v5.0.11 — GitHub 웹 업로드 및 Firebase 규칙 적용

1. 현재 GitHub에 v5.0.10이 설치되어 있는지 확인하세요.
2. purplekit-v5.0.10-to-v5.0.11-web-upload.zip을 내려받아 압축을 해제합니다.
3. 압축을 푼 안쪽 파일/폴더를 모두 선택해 GitHub 저장소의 최상위(기존 index.html이 있는 곳)에 올려 덮어씁니다.
   'classroom-quiz-lab-main' 폴더가 중복 생성되지 않도록 주의하세요.
4. Commit changes로 적용합니다.
5. Firebase Realtime Database → 규칙에 v5.0.11 통합 보안 규칙을 게시합니다.
   방법: 업데이트된 퍼플킷 게임 방 관리에서 'v5 전체 통합 규칙 복사' → Firebase 콘솔에 붙여넣기 → 게시.
   주의: Firebase 규칙은 GitHub 파일을 업로드하기만 해서는 자동으로 바뀌지 않습니다.
6. 종료된 테스트 방 한 개를 선택하여 삭제 실험을 해본 다음 사용하세요.

사용법
- 방 목록에서 체크박스를 여러 개 선택 → 선택한 방 삭제 (N) → 확인
- '입장 마감·종료 방 선택'으로 오래된 후보를 한꺼번에 선택할 수 있습니다.
- 실제 게임이 진행 중이거나 학생이 접속 중이면 방을 삭제하지 않습니다.
- 삭제 시 해당 방의 학생, 점수, 문제별 결과 기록을 모두 삭제하며 복구할 수 없습니다.
- 공용 문제 세트는 삭제하지 않습니다.
- 오류가 난 방은 남고 성공한 방만 삭제됩니다.

규칙 변경 이유: 기존 클래식(v3) 답안 경로는 교사가 방 단위로 삭제할 권한이 없어 일괄 삭제가 실패할 수 있었기 때문입니다.
