# 퍼플킷 v5.0.6 — 피싱 프렌지 이미지 문항 오류 수정 + 교사 진행 현황

## 이번 업데이트
- 문제 화면의 이미지 URL 변환 오류 수정: `fullQuestionImageUrl(own.imageUrl, location.href)`
- 보기를 먼저 생성한 뒤 이미지 처리; 그림 주소가 잘못됐거나 파일이 없어도 보기·입력창을 유지하고 경고 표시
- 교사 방 관리에 학생별 진행 상태 및 전체화면 전광판 추가
- 버전 확인을 `APP_VERSION=5.0.6`, `APP_BUILD=506`, `version.json build=506`으로 통일; 화면/JS 캐시 식별자 갱신
- 기존 골드/클래식/Firebase 보안 규칙/문제 및 점수 데이터는 건드리지 않음

## 업데이트 방법
- 현재 v5.0.5가 GitHub에 있다면 `purplekit-v5.0.5-to-v5.0.6-web-upload.zip`의 압축을 풀어 저장소 최상위에 해당 경로 그대로 업로드하고 Commit changes
- 게임 도중 업데이트 금지. 교사와 학생 모두 **기존 탭을 닫고 새로 접속**하여 v5.0.6 확인
- Firebase Realtime Database 규칙은 변경할 필요 없음

## 검증 및 제약
- 기존 이미지 URL 함수 문제는 재현 후 수정
- 교사 현황은 **Firebase에 이미 저장된 낚시 상태와 답안 제출**로부터 산출함. 브라우저 렌더링 오류까지 원격으로 직접 감지하지는 못함
- 학생 20~30명 동시 플레이 및 Firebase 실제 네트워크 테스트는 배포 후 검증 필요
- 이미지가 없는 문제에서 동일 증상이 다시 나타나면 해당 문항 번호/브라우저 콘솔 오류 기록을 확보해야 함
