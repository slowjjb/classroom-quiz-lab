# 퍼플킷 v4.7 — 골드 퀘스트 반복 문제 보기 순서 개선

## 왜 수정했나요?
- v4.6은 같은 문항이 **직전** 출제되었을 때의 보기 순서와 정답 위치만 회피했습니다.
- 세 번째·네 번째 등장하는 문제는 처음 사용했던 순서로 다시 돌아갈 수 있었습니다.
- 교사용 `rooms.html`이 구버전으로 캐시되면 보기 섞기를 교사 쪽에서 적용하지 못할 수 있으므로, 이번에는 교사용 JS 주소도 `?v=4.7`로 바꿨습니다.

## 변경된 동작
- 골드 퀘스트 **객관식 보기 4개**의 가능한 24가지 배열을 한 번씩 사용한 후에만 기존 배열을 다시 사용합니다.
- 같은 문항이 네 번 출제되는 동안 정답 위치가 1~4번에 한 번씩 나타납니다. 다음 네 번에서도 같은 방식으로 균등하게 순환합니다.
- 같은 문제가 학생별로 각각 다른 순서로 출제될 수 있습니다.
- 보기 순서 대응표가 교사 권한으로 기록되므로 채점 및 정답 분석이 원래 선택지에 맞게 유지됩니다.
- 기존 v4.6의 보기 기록(`optionHistory` 배열)을 읽어 새 기록 형식으로 자동 전환합니다. 기존 문제/게임 기록은 삭제하지 않습니다.
- 주관식, 클래식, BGM, 골드 보상, 문항 이미지, Firebase 규칙은 변경하지 않았습니다.

## 설치 방법 (v4.6 → v4.7)
1. `purplekit-v4.7-upgrade.zip`을 내려받아 압축을 풀어 주세요.
2. GitHub 저장소 `slowjjb/classroom-quiz-lab` → Add file → Upload files.
3. ZIP이 아니라 **압축 해제된 내용물**을 저장소 최상위에 올려 주세요. `js`와 `tests` 폴더도 포함해 기존 파일을 덮어쓰기 합니다.
4. Commit changes 후 GitHub Pages 배포를 기다려 주세요.
5. 교사 `rooms.html`과 학생 `join.html`을 모두 Ctrl+Shift+R로 강력 새로고침하고 화면의 버전이 `v4.7`인지 확인하세요.
6. **새 골드 퀘스트 방**에서 문제 세트 2~4문항을 사용하여 같은 문항이 반복되는지 테스트하세요. 기존 게임 진행 중 재배포는 권장하지 않습니다.

## Firebase
- **Realtime Database 보안 규칙 변경 없음.** 기존 v4 통합 규칙 그대로 사용합니다.
- `firebase-config.js`, `database.rules.json`, 이미 운영 중인 학생 거래 내역은 건드리지 않습니다.

## 검증
- Node 기반 자동 테스트 **26개 통과**(신규 24순열 회전 테스트 포함).
- 4가지 정답 위치, 24개 보기 배열의 중복 방지, v4.6 기록 호환, Firebase JSON 직렬화 후 기록 복구, 정답 번호 재매핑, BGM·분석 기능 기존 회귀 테스트.
- JavaScript 문법 검사 통과.
- **현장 학교 기기·Firebase 실시간 접속은 아직 확인 전**입니다. 교사와 학생 양쪽 버전이 맞는지 꼭 확인하세요.

## 추가 안내
- 서로 똑같은 문구의 보기가 여러 개 들어간다면 보기를 내부적으로 섞어도 눈으로는 같은 배열처럼 보일 수 있습니다. 서로 구분 가능한 보기 4개를 권장합니다.
